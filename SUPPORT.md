# Support

## Before requesting help

1. Read the root README and the relevant guide in `docs/`.
2. Confirm dependencies are installed with `npm ci`.
3. Run the applicable Prisma and TypeScript checks.
4. Check the troubleshooting section in the README.
5. Reproduce the issue with a non-production account and synthetic data.

## Bug reports

Use the GitHub bug report template. Include the affected page or API procedure, expected behavior, actual behavior, reproducible steps, runtime details, and sanitized logs.

## Security issues

Do not report exploitable vulnerabilities or leaked credentials in a public issue. Follow [SECURITY.md](SECURITY.md).

## What not to share

Never include API keys, Authorization headers, Clerk session cookies, Stripe secrets, database URLs, private event payloads, or personal customer data in public discussions.

## Project scope

This repository contains the PingPanda web application and API implementation. It does not, by itself, establish a production uptime SLA or guaranteed event delivery service.
